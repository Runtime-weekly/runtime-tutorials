# Questions, corrections and contributions

Questions are welcome, including installation questions. Check the README and
existing issues first, then choose a question or problem report in the Issues tab.

For a fix, describe the problem, provide a small synthetic example, explain your
change and say exactly what you tested. Keep unrelated changes separate. Do not
claim a platform was tested because its commands look similar.

Before sharing code, screenshots or logs, remove personal data, access tokens,
private addresses and customer information. Do not upload model weights, virtual
environments, generated run folders or production logs. Use short, invented
examples. Never put a password or token into a support issue.

Published results must distinguish fresh runs from saved examples and preserve
known limitations. Claims about new releases should link to primary sources.

Security reports should follow [SECURITY.md](SECURITY.md), not a public issue.
